# Terrifying Challenge

> The modern edition of the annual October horror movie marathon web app.

🔗 **Live Demo:** [https://fooly-cooly.github.io/Terrifying-Challenge/](https://fooly-cooly.github.io/Terrifying-Challenge/)

---

## Overview

**Terrifying Challenge** is a feature-rich, interactive horror film challenge portal for October. It expands upon the original challenge with dynamic film archives, secret reveals, and advanced rulesets.

### Features

- 🎬 **Multi-Year Marathon Lists:** Comprehensive collections spanning 2017 through 2023.
- 🔒 **Secret Films:** Hidden mystery film picks unlocked on October 28th.
- 📜 **Advanced Rulesets:** Modal rules selector including *Lax*, *Retro*, and *Curator* modes.
- ⚡ **Optimized Performance:** Lazy-loaded high-resolution poster artwork using [Lozad.js](https://apoorv.pro/lozad.js/).
- 🎞️ **Atmospheric Media:** Responsive video trailers, audio, and custom animations.

---

## Technologies Used

- **HTML5 & CSS3**
